# El tono: ni robot ni colega

No se arregla con adjetivos ("natural, cercano pero profesional"): cada modelo los interpreta a su
manera. Se arregla con **coordenadas + ejemplos**.

1. **4 ejes explícitos** en el prompt: **formalidad** (tuteo/usted) · **energía** (sobrio ↔ entusiasta)
   · **longitud** ("2-3 frases, máx. 40 palabras salvo que pidan detalle") · **emoji y jerga**.
2. **Lista negra de muletillas**, literal. Funciona mejor que cualquier descripción abstracta.
3. **Dos ejemplos de oro escritos por ti** como few-shot: el modelo imita el registro mucho mejor de lo
   que obedece una instrucción.
4. **Un ejemplo de lo que NO quieres**, marcado como tal ("❌ así no").
5. Si el cliente tiene voz de marca, destila las reglas de **textos suyos reales**, no la inventes.
6. **Vuelve a pasar las evaluaciones** después de tocar el tono: subir la simpatía baja la obediencia a
   los límites.
